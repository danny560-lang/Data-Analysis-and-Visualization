# Data Analysis and Visualization

Jupyter notebooks for data cleaning, analysis and visualization, written with pandas and matplotlib for SNHU coursework.

| Folder | What it is |
|---|---|
| `module-2/` | Data exploration and coding samples |
| `module-3/` | Weather data analysis |
| `module-5-college-scorecard/` | Visual exploration of the U.S. College Scorecard field-of-study data |
| `module-6-covid-dashboard/` | COVID-19 total deaths dashboard |
| `module-9-project/` | Final project: data blending, cleaning and analysis |

The College Scorecard CSV (about 150 MB) is not included because it's over GitHub's file size limit. You can download it from collegescorecard.ed.gov.
